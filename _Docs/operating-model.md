# The Operating Model — one page

> **Internal.** For the educational leader and team. Not for parents — there's a
> simpler version for them. The test of this page: it should run a Friday
> reflection without anyone opening a diagram.

---

## The conviction
Play-based, inquiry-led learning, with intentional structure where it serves the
child. **We lead with play on purpose.**

## The house, in one breath
- **Ground:** the frameworks we build on — EYLF → VEYLDF.
- **Foundation:** our philosophy (above).
- **Four pillars (the day, running in parallel):**
  - **Pedagogy** — how we teach: EXPLORE, intentional teaching, relationships.
  - **Curriculum** — what's experienced: five domains, planned + spontaneous, indoor + outdoor.
  - **Program** — how it's organised: daily rhythm, routines, environments.
  - **Experiences** — the lived day: play & inquiry, documented.
- **Roof:** outcomes — school-ready, life-ready (the three minds; the five VEYLDF outcomes).

## The engine — the planning cycle (this *is* the job)
**Observe → Plan → Implement → Reflect → repeat.** Cadence that keeps it real:

- **Daily** — observe & jot. Each educator captures 2–3 real moments (a photo, a quote, a note).
- **Weekly** — team plan, 30 minutes. Read the week's observations → set intentions for next week → name which children need what.
- **Termly** — deeper reflection. What's emerging across the group? Where does each child sit on the Victorian Learning Progressions? What changes to environment or program?
- **Always** — families and community feed the cycle at **Observe** ("what's this child like at home?") and **Reflect** ("here's what we're noticing — what do you see?").

## Run the Friday meeting off these five prompts
1. What did we observe this week that *surprised* us?
2. Where did a child hit "safe but stretching" — and where did we rescue too soon?
3. Which EXPLORE element was thin this week? (Did every child get to lead? Did we pause to reflect *with* them?)
4. Whose learning are we not yet seeing clearly? (Usually the quiet child.)
5. One concrete change to the environment or program for next week.

## Keep the cycle fed (inputs)
- **Families:** enrolment conversations, daily handovers, termly learning conversations.
- **Community & culture:** local connections, Country, home languages.
- **Research & PD:** the EY Hub modules, EYALT, Teaching Excellence; one shared reading per term.
- **Documentation:** the thinking wall + project journals — visible, current, in the child's voice.

## What the assessor sees (the NQS link)
This cycle *is* **Quality Area 1** (educational program & practice). The documentation,
the planning cycle, and the educational leader's role are exactly what gets rated.
Run it for the children; it passes the assessment as a by-product. (Note: from Jan 2026
the NQS sharpened its focus on QA2 — health & safety — and QA7 — governance &
leadership. Build policy and structure to those.)
